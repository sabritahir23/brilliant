Review queue phase

Find signal locally, spend official reviews carefully

We fetch lots of PGNs first, run the local detector quickly, rank likely Brilliant-like games, send top-ranked plus random/control games to Chess.com Review, then use those official labels to improve the detector.

  1. FetchBuild a broad PGN pool.
  2. PredictFind and rank Brilliant-like candidates locally.
  3. ReviewCheck top-ranked and random/control games officially.
  4. LearnUse official labels to evaluate and improve the detector.

Random/control sampling helps avoid bias, reveals candidates the current detector misses, and gives a more honest view of recall. Ranked queue generation is a future implementation step; this screen currently prepares the local candidate pool.
